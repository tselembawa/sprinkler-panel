# Modbus RTU: controller ↔ modules — χάρτης registers v1

Κατάσταση: **πρώτη έκδοση, προς έγκριση**. Ισχύει για το module 4 εισόδων / 4 εξόδων (τύπος 0x0404).

## 1. Βασικοί κανόνες

- **Modbus RTU, 38400 baud, 8N1** (η ταχύτητα της πρώτης δοκιμής RS485).
- Ο **controller είναι ο μόνος master**. Ένα module μιλάει μόνο όταν το ρωτήσουν.
- **Διευθύνσεις** ανά γραμμή: L1 1–60, L2 61–120, L3 121–180, L4 181–240. Το **0** είναι broadcast (μόνο για το SYNC, χωρίς απάντηση).
- Όλα τα registers είναι **16 bit**, το πιο σημαντικό byte πρώτο (κανόνας Modbus). Οι διευθύνσεις registers μετρούν από 0.
- **Τα modules δεν αποθηκεύουν ρυθμίσεις και δεν αποφασίζουν.** Η ρύθμιση ζει μόνο στον controller (FRAM) και στέλνεται στο module κάθε φορά που ξεκινά. Ένα καινούργιο module μπαίνει στη θέση του παλιού χωρίς προγραμματισμό· αρκεί η ίδια διεύθυνση στα DIP.
- Το module αναφέρει τη **φυσική** κατάσταση της επαφής (κλειστή / ανοιχτή). Το αν αυτό σημαίνει «Normal» ή «Aktiv» το αποφασίζει ο controller από το NO/NC της larmpunkt.
- Εντολές Modbus που υποστηρίζονται:

| Κωδικός | Όνομα | Χρήση |
| --- | --- | --- |
| 04 | Read Input Registers | κατάσταση και ταυτότητα (μόνο ανάγνωση) |
| 03 | Read Holding Registers | ανάγνωση εντολών και ρυθμίσεων (έλεγχος) |
| 06 | Write Single Register | μία εντολή (π.χ. έξοδοι) |
| 16 (0x10) | Write Multiple Registers | όλη η ρύθμιση με μία φορά |

## 2. Input registers (εντολή 04) — από το module προς τον controller

### 2.1 Ταυτότητα — 0x0000–0x0007

Διαβάζεται στο discovery και κάθε φορά που το module ξεκινά.

| Διεύθυνση | Όνομα | Περιεχόμενο |
| --- | --- | --- |
| 0x0000 | MODULE_TYPE | 0x0404 = module 4 εισόδων / 4 εξόδων |
| 0x0001 | MAP_VERSION | 1 (έκδοση αυτού του χάρτη) |
| 0x0002 | FW_VERSION | major × 256 + minor (0x0100 = 1.0) |
| 0x0003 | HW_VERSION | αναθεώρηση πλακέτας |
| 0x0004 | SERIAL_HI | serial number, πάνω 16 bit (μόνο πληροφορία) |
| 0x0005 | SERIAL_LO | serial number, κάτω 16 bit |
| 0x0006 | DIP_ADDRESS | η διεύθυνση που διαβάζει τώρα από τα DIP |
| 0x0007 | – | δεσμευμένο (0) |

### 2.2 Γρήγορη κατάσταση — 0x0010–0x0013

Διαβάζεται **σε κάθε κύκλο** (4 registers).

| Διεύθυνση | Όνομα | Περιεχόμενο |
| --- | --- | --- |
| 0x0010 | STATUS | σημαίες κατάστασης (βλ. 2.4) |
| 0x0011 | INPUTS | IN1–IN4, 4 bit η καθεμία: IN1 = bit 0–3, IN2 = bit 4–7, IN3 = bit 8–11, IN4 = bit 12–15 |
| 0x0012 | OUTPUTS | OUT1–OUT4, 4 bit η καθεμία, ίδια σειρά |
| 0x0013 | CHANGES | μετρητής: +1 σε κάθε αλλαγή εισόδου ή εξόδου |

**Τιμές εισόδου (4 bit)**

| Τιμή | Όνομα | Τι σημαίνει (EOL 1 kΩ σε σειρά + 1 kΩ παράλληλα) |
| --- | --- | --- |
| 0 | CLOSED | επαφή κλειστή (≈ 1 kΩ) |
| 1 | OPEN | επαφή ανοιχτή (≈ 2 kΩ) |
| 2 | LINE_OPEN | κομμένο καλώδιο (Avbrott, ∞) |
| 3 | LINE_SHORT | βραχυκύκλωμα (Kortslutning, ≈ 0) |
| 4 | NOT_USED | η είσοδος δεν χρησιμοποιείται |
| 5 | MEASURE_FAULT | η μέτρηση είναι εκτός ορίων ή αδύνατη |

**Τιμές εξόδου (4 bit)**: το **bit 3** = η έξοδος είναι ενεργή αυτή τη στιγμή· τα **bit 0–2** = επιτήρηση: 0 OK, 1 LINE_OPEN, 2 LINE_SHORT, 3 OVERCURRENT, 4 NOT_SUPERVISED.

### 2.3 Λεπτομέρειες — 0x0014–0x0022

Διαβάζονται **όταν αλλάξει ο CHANGES, κάθε 10ο κύκλο** και όταν ο τεχνικός ανοίγει την οθόνη σέρβις. Μαζί με το 2.2 είναι ένα συνεχές μπλοκ 0x0010–0x0022 (19 registers, μία ερώτηση).

| Διεύθυνση | Όνομα | Περιεχόμενο |
| --- | --- | --- |
| 0x0014–0x0017 | IN1–IN4_CHANGES | μετρητής αλλαγών ανά είσοδο: ένα σύντομο «Aktiv» ανάμεσα σε δύο ερωτήσεις δεν χάνεται |
| 0x0018–0x001B | IN1–IN4_OHM | αντίσταση βρόχου σε Ω (0xFFFF = ανοιχτό) |
| 0x001C–0x001F | OUT1–OUT4_MA | ρεύμα εξόδου σε mA |
| 0x0020 | SUPPLY_MV | τάση 24 V όπως φτάνει στο module, σε mV |
| 0x0021 | TEMP | θερμοκρασία πλακέτας σε °C × 10 (με πρόσημο) |
| 0x0022 | CRC_ERRORS | πόσα χαλασμένα πακέτα έχει δει το module |

### 2.4 STATUS — σημαίες

| Bit | Όνομα | Πότε ανάβει / σβήνει |
| --- | --- | --- |
| 0 | RESTARTED | το module ξεκίνησε (ρεύμα ή reset) και δεν έχει πάρει ρύθμιση. Σβήνει με COMMAND = CONFIG_DONE |
| 1 | FAILSAFE | έμεινε χωρίς ερώτηση πάνω από COMM_TIMEOUT και έβαλε τις εξόδους σε κατάσταση ασφαλείας. Σβήνει με CLEAR_FLAGS |
| 2 | SUPPLY_LOW | τάση κάτω από το όριο SUPPLY_LOW (προεπιλογή 14,0 V) |
| 3 | SUPPLY_HIGH | τάση πάνω από 30,0 V |
| 4 | INTERNAL_FAULT | ο αυτοέλεγχος απέτυχε (ADC, τάση αναφοράς, θερμοκρασία) |
| 5 | DIP_CHANGED | άλλαξαν τα DIP μετά την εκκίνηση· η νέα διεύθυνση ισχύει μόνο μετά από επανεκκίνηση |
| 6 | IDENTIFY | αναβοσβήνει το LED αναγνώρισης |
| 7–15 | – | 0 |

## 3. Holding registers (εντολές 03 / 06 / 16) — από τον controller προς το module

### 3.1 Εντολές — 0x0100–0x0102

| Διεύθυνση | Όνομα | Περιεχόμενο |
| --- | --- | --- |
| 0x0100 | OUT_CMD | OUT1–OUT4, 4 bit η καθεμία: 0 OFF, 1 ON, 2 FLASH (1 Hz), 3 FLASH_FAST (2 Hz), 4 PULSE (ON για PULSE_TIME, μία φορά όταν γραφτεί) |
| 0x0101 | COMMAND | ενέργεια μίας φοράς (βλ. 3.3). Διαβάζεται πάντα 0 |
| 0x0102 | SYNC | με broadcast (διεύθυνση 0): όλα τα modules ξεκινούν το αναβόσβημα μαζί |

### 3.2 Ρύθμιση — 0x0110–0x011C

Γράφεται **με μία εντολή 16** κάθε φορά που το module ξεκινά.

| Διεύθυνση | Όνομα | Περιεχόμενο | Προεπιλογή |
| --- | --- | --- | --- |
| 0x0110 | COMM_TIMEOUT_S | δευτερόλεπτα χωρίς ερώτηση πριν το failsafe (2–60) | 10 |
| 0x0111 | FAILSAFE_OUT | κατάσταση εξόδων στο failsafe, 4 bit ανά έξοδο: 0 OFF, 1 ON, 2 HOLD (κρατά την τελευταία), 3 FLASH | HOLD |
| 0x0112 | DEBOUNCE_MS | φίλτρο εισόδων (20–2000 ms) | 100 |
| 0x0113 | PULSE_100MS | διάρκεια PULSE σε δέκατα του δευτερολέπτου | 10 (= 1 s) |
| 0x0114–0x0117 | IN1–IN4_CFG | χαμηλό byte: 0 NOT_USED, 1 SUPERVISED (με EOL), 2 UNSUPERVISED (σκέτη επαφή, χωρίς έλεγχο γραμμής). Υψηλό byte: προφίλ EOL (0 = 1 kΩ + 1 kΩ) | 1 / προφίλ 0 |
| 0x0118–0x011B | OUT1–OUT4_CFG | χαμηλό byte: 0 NOT_USED, 1 χωρίς επιτήρηση, 2 SUPERVISED (επιτήρηση γραμμής με αντίστροφη πολικότητα). Υψηλό byte: όριο ρεύματος σε 10 mA (50 = 500 mA) | 2 / 50 |
| 0x011C | SUPPLY_LOW | όριο χαμηλής τάσης σε δέκατα του V (100–300) | 140 (= 14,0 V) |

### 3.3 Τιμές του COMMAND

| Τιμή | Όνομα | Τι κάνει |
| --- | --- | --- |
| 1 | CONFIG_DONE | η ρύθμιση γράφτηκε· σβήνει το RESTARTED |
| 2 | CLEAR_FLAGS | σβήνει FAILSAFE και DIP_CHANGED, μηδενίζει CRC_ERRORS |
| 3 | IDENTIFY_ON | αναβοσβήνει το LED του module για 60 s («Hitta modul» από την οθόνη) |
| 4 | IDENTIFY_OFF | σταματά το IDENTIFY |
| 5 | REBOOT | επανεκκίνηση του module |

Άγνωστη τιμή → εξαίρεση 03.

## 4. Κύκλος και χρονισμοί

- Το module απαντά σε **≤ 10 ms**· ο controller περιμένει **50 ms**.
- Κενό ανάμεσα σε πακέτα **≥ 1,75 ms** (κανόνας Modbus πάνω από 19200 baud).
- **Κάθε κύκλο**, για κάθε module: εντολή 04 στο 0x0010, 4 registers ≈ 8 ms. 60 modules ≈ **0,5 s ανά γραμμή**· οι γραμμές δουλεύουν παράλληλα.
- **Όταν αλλάξει ο CHANGES** (ή κάθε 10ο κύκλο): εντολή 04 στο 0x0010, 19 registers.
- **Εντολή εξόδων** (06 στο 0x0100) μόνο όταν αλλάζει.
- Κάθε έγκυρη ερώτηση προς το module μηδενίζει τον μετρητή COMM_TIMEOUT.
- **3 συνεχόμενοι κύκλοι χωρίς έγκυρη απάντηση** (≈ 1,5 s) → fault **MODULE_LOST** για το module και όλα τα σημεία του.

### Παράδειγμα: L1-M02, IN1 serviceventil (NC), IN2 pressostat (NO), IN3–IN4 ej använda

Ερώτηση του controller: `02 04 00 10 00 04 <CRC>` (module 2, εντολή 04, από 0x0010, 4 registers).

| Κατάσταση | INPUTS | Ο controller βγάζει |
| --- | --- | --- |
| Όλα σε ηρεμία | 0x4410 → IN1 = 0 CLOSED, IN2 = 1 OPEN, IN3/IN4 = 4 | IN1 NC κλειστή = Normal, IN2 NO ανοιχτή = Normal |
| Νερό στο σύστημα | 0x4400 → IN2 = 0 CLOSED | IN2 NO κλειστή = **Aktiv** → A-larm (latching) |
| Κόβεται το καλώδιο της βάνας | 0x4412 → IN1 = 2 LINE_OPEN | **Fel: Avbrott** στο IN1 |

## 5. Εκκίνηση module και discovery

**Για κάθε module ο controller:**

1. Διαβάζει την ταυτότητα (04, 0x0000, 8 registers).
2. Ελέγχει MODULE_TYPE, MAP_VERSION, DIP_ADDRESS και ότι η διεύθυνση ανήκει στην περιοχή της γραμμής. Αλλιώς fault **«fel modultyp»** ή **«fel linje»**.
3. Γράφει τη ρύθμιση (16, 0x0110, 13 registers).
4. Γράφει COMMAND = CONFIG_DONE.
5. Συνεχίζει με την κυκλική ερώτηση.

Αν αργότερα δει **RESTARTED**, καταγράφει συμβάν **MODULE_RESTART** και ξεκινά πάλι από το βήμα 3.

**DISCOVER** (από την οθόνη, μόνο τεχνικός): ο controller ρωτά την ταυτότητα σε όλες τις διευθύνσεις της περιοχής κάθε γραμμής (π.χ. L1: 1–60) με αναμονή 20 ms (≈ 1,2 s ανά γραμμή) και δίνει στο HMI λίστα με διεύθυνση, τύπο, serial και firmware.

## 6. Εξαιρέσεις Modbus

| Κωδικός | Πότε |
| --- | --- |
| 01 | εντολή που δεν υποστηρίζεται |
| 02 | διεύθυνση register που δεν υπάρχει |
| 03 | τιμή εκτός ορίων (π.χ. COMM_TIMEOUT = 0) |
| 04 | εσωτερικό σφάλμα του module |

## 7. Αποφάσεις και ανοιχτά θέματα

1. **Failsafe εξόδων — αποφασίστηκε:** όταν το module χάσει τον controller, οι έξοδοι **κρατούν την κατάσταση που είχαν** (HOLD).
2. **Όρια τάσης — αποφασίστηκε:** χαμηλή τάση **14,0 V** (ρυθμιζόμενη ανά εγκατάσταση, 10–30 V), υψηλή 30,0 V. Τα ηλεκτρονικά του module δουλεύουν από 10 V· οι συσκευές στις εξόδους πρέπει να δουλεύουν στην τάση που φτάνει.
3. **Ταχύτητα 38400 baud** ως οριστική — ανοιχτό.
